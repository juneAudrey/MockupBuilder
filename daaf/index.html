        📖 Daaf Wave 사용법
        
      


      
      

        
        
        
        
        
        
        
        
      


      


        
        

          
💡 상단 스위치로 DB 연결 · 오프라인 중 하나를 먼저 선택하세요.

          
1
            
모드 선택
상단에서 DB 연결 / 오프라인 중 하나를 고릅니다. DB 연결은 DB 종류 3종에서 MSSQL·MySQL·Oracle 중 하나를 선택합니다.

          

          
2
            
검색 → 파도타기
프로그램을 검색해 고른 뒤, 볼 범위(UI WF Rp Mo)를 정하고 [▶ 연관 조회 실행]을 누릅니다. 깊이 제한 없이 끝까지 연관을 따라가며, 너무 오래 걸리면 옆의 [✕ 취소] 로 언제든 중단할 수 있습니다.

          

          
3
            
확인 → 저장
더블클릭하면 좌측 UI 탭에 그 화면의 디자인이 바로 뜨고, 그래프·테이블·흐름도로도 관계를 살펴볼 수 있습니다. 필요한 항목을 바구니에 담아 JSON/CSV로 저장합니다.

          

          

            
🔒 읽기 전용
연결된 DB에는 조회(SELECT)만 수행합니다. 쓰기는 코드 차원에서 차단됩니다.

            
❓ 도움말
상단 [❓ 사용법] 버튼으로 이 가이드를 언제든 다시 열 수 있습니다.

          

        


        
        

          
1
            
검색어 입력
프로그램 ID 또는 메뉴명을 넣고 [프로그램 검색]을 누릅니다. 결과는 메뉴명이 첫 컬럼에 오도록 정렬되고, 건수가 "검색 결과 N건"으로 표시됩니다.

          

          
2
            
결과에서 선택
행을 클릭해 고르거나 더블클릭하면 곧바로 파도타기가 실행됩니다. 헤더의 전체 선택 체크박스로 여러 개를 골라 일괄 저장과 연계할 수 있습니다.

          

          

            📁 상위 폴더로 찾아보기 검색형 콤보▾
            

              상위 폴더 입력칸을 클릭하면 트리 전체가 펼쳐지고, 글자를 입력하면 경로 어디든 일치하는 폴더만 즉시 걸러집니다. 폴더를 고르면 그 폴더·하위 폴더의 모든 프로그램이 한 번에 조회됩니다.
              
    
                
  • ↑ ↓ 이동 · Enter 선택 · × 초기화 · ↻ 목록 새로고침
    • 
                
  • DB 연결 · 오프라인 모두 지원
    • 
                
  • 오프라인은 [⚙ 데이터 관리]에서 메뉴를 먼저 받고, "제품"을 특정 값(예: ERP)으로 선택해야 합니다("전체" 미지원).
    • 
              

            

          

          

            ⚙ 고급 옵션 · WF 직접 검색▾
            

              테넌트·회사·언어처럼 자주 바꾸지 않는 값은 [⚙ 고급 옵션]을 눌러야 보입니다(기본 *).

              WF만 바로 찾으려면 검색 대상을 WF로 두고 서비스 ID(예: IMMVCMUI0002_SELECT) 또는 서비스 UID로 검색합니다.
            

          

        


        
        

          
🌊 선택한 프로그램에서 서비스 관계를 재귀적으로 확장합니다. 연결된 UI·WF·Report·Mobile을 한 화면에 모읍니다.

          
1
            
볼 범위 선택
각 칩을 켜고 끕니다(기본 UI WF Rp). 선택된 칩은 진한 배경 + 체크(✓), 꺼진 칩은 옅은 테두리로 표시됩니다.

          

          
2
            
[▶ 연관 조회 실행 (파도타기)]
깊이 제한 없이 끝까지 연관을 따라가며 확장됩니다. 결과가 그래프·테이블·흐름도에 채워지고, 순환참조는 빨간 점선으로 표시됩니다. 오래 걸리면 실행 버튼 옆 [✕ 취소] 로 중단할 수 있습니다.

          

          

            🧩 무엇을 어떻게 잇는가▾
            

              공통 연결키는 serviceUid(숫자), serviceId(문자)는 라벨로 쓰입니다.
              
    
                
  • UI Mo — serviceUid · serviceId · 실행 경로
    • 
                
  • Rp — 상동 + 참조 테이블
    • 
                
  • WF — 하위 serviceUid · 테이블명 · SQL의 FROM/JOIN/INTO/UPDATE 테이블
    • 
              

              노드 클릭 시 우측 상세 패널에서 참조 테이블·하위 서비스·버튼→이벤트 트리거·공통코드(MAJOR_CD/MINOR_CD)를 확인할 수 있습니다.
            

          

        


        
        

          
🖥 그래프 왼쪽 [UI] 탭 — 검색 결과를 더블클릭하면 팝업 없이 바로 그 화면의 디자인이 뜹니다. 코드·디자인 보기 팝업의 "디자인" 모드와 사용법이 동일합니다.

          
1
            
뱃지로 화면 이동
라벨 오른쪽의 WF/UI/Rp 뱃지를 누르면: UI/Mo/Rp는 탭 안에서 바로 그 화면으로 전환([◀ 뒤로]로 되돌아가기), WF는 그래프에 그 노드를 선택·확대해 둔 뒤 흐름도 탭으로 이동합니다.

          

          
2
            
초기값(IV) 배지
클릭하면 그 필드의 초기값 추적 결과가 패널로 뜹니다. 같은 배지를 다시 누르면 닫힙니다.

          

          
3
            
그리드 컬럼 표
그리드는 제목·뱃지 2줄짜리 컬럼 표로 재현됩니다. z_grid_columns/z_grid_options에 실시간 값이 있으면(관리자가 그리드 커스터마이징으로 배포 없이 바꾼 순서·표시여부 등) 배포 스냅샷 대신 그 값을 우선 보여줍니다.

          

          

            
🔎 리포트(Rp) 도구
Rp 화면엔 확대/축소·PDF/이미지 저장·연결된 WF 쿼리 패널이 함께 뜹니다. 툴바의 [🔎 쿼리]로 그 패널을 통째로 숨겨 리포트를 넓게 볼 수 있습니다.

            
🔗 상세 패널 연동
탭 안에서 화면을 옮길 때마다 우측 상세 패널도 지금 보고 있는 노드 정보로 함께 바뀝니다.

🎛 배치 방식 NEW

    • 
                
  • 미니맵 NEW — 좌상단에서 현재 위치 확인(클릭·드래그 이동, 제목줄 드래그로 위치 옮김·저장, 체크박스로 on/off)
    •

    • 
              

            

          

          

            📄 단계 상세 · SQL 확인▾
            

              
    
                
  • 단계 클릭 → 우측 팝업에 쿼리·조건식·메시지 원본 표시 및 복사
    • 
                
  • 팝업은 [▾ 접기]/[▸ 펼치기] 가능(상태는 다른 단계·WF로 이동해도 유지)
    • 
                
  • 상세의 각 "SQL 쿼리" [🔀 이동] → 흐름도에서 그 쿼리 단계로 바로 이동·선택·줌
    • 
              

            

          

          

            ↗ 서비스콜 단계로 바로 이동 NEW▾
            

              다른 WF를 호출하는 단계는 점선 테두리 + 옅은 보라 + "↗"로 구분됩니다.
              
    
                
  • 더블클릭 또는 [🔀 이 서비스 흐름도 보기] → 그 WF 흐름도로 즉시 전환
    • 
                
  • 이동 후 [◀ 뒤로] → 원래 보던 WF의 그 단계로 정확히 복귀(연달아 이동 시 순서대로 되짚음)
    • 
                
  • 그 서비스가 파도타기 결과에 없으면(취소로 중단됨·DB 미발견 등) 이유를 상태 표시줄에 안내
    • 
              

            

          

        


        
        

          

            
🧺 부분 저장 (바구니)
체크박스나 [+ 바구니에 담기]로 원하는 노드만 모아 JSON/CSV로 저장합니다.

            
📦 일괄 저장 (전체) 자동
검색 결과에 체크된 항목이 있으면 그것들을 합쳐 파도타기해 저장, 없으면 지금 조회 중인 데이터를 저장.

          

          
💡 여러 개를 헤더 체크박스로 골라(폴더 전체 포함) [일괄 저장(전체)]을 누르면 연관 데이터가 하나로 합쳐져 바로 저장됩니다. 화면(그래프·테이블)은 그대로 유지되고, 항목이 많아 화면 반영이 느려도 저장은 끝까지 진행됩니다.

          

            🗂 저장되는 파일▾
            

              출력 폴더 wave_<프로그램ID>_<일시>/ 아래에 생성(4개 배포정보 테이블의 모든 컬럼 원본 포함):
              
    
                
  • *.json — 노드 + 관계 + 각 노드 원본 레코드(AI 재분석 최적)
    • 
                
  • *_UI/WF/Rp/Mo.csv — 타입별 전체 컬럼 CSV(엑셀 한글 BOM 포함)
    • 
                
  • *_TABLE.csv — 참조 테이블 · *_EDGES.csv — 관계(from/to/relType)
    • 
              

            

          

        


        
        

          
⤓ 대용량 배포정보를 로컬에 내려받아 DB 연결 없이 조회·저장할 수 있습니다. 상단 [⚙ 데이터 관리]로 관리합니다.

          

            
⤓ 전체 다운로드
테이블별 SQLite로 저장 — 1GB 규모도 빠르게 조회합니다.

            
↻ 증분 갱신
변경분만(UPDT_DT 기준) 반영. 삭제 행 정리는 [선택 테이블 삭제]로.

            
📁 메뉴·폴더
메뉴를 받으면 트리(L1~L6)까지 저장되어 오프라인에서도 폴더 찾기가 동작합니다.

            
🧩 그리드 실시간 구성 NEW
z_grid_columns/z_grid_options(테넌트 오버라이드 포함)도 받아두면, UI 탭의 그리드 컬럼 표가 배포 스냅샷 대신 최신 커스터마이징 값을 보여줍니다.

            
⏱ 진행률·중단
실시간 진행률과 [■ 강제 중단]. 대용량에서도 화면이 멈추지 않습니다.

          

          

            🗄 DB 연결 · 접속정보 관리▾
            

              
    
                
  • DB 종류에서 MSSQL·MySQL·Oracle 선택(포트 기본값 자동: 1433/3306/1521)
    • 
                
  • 별칭으로 접속정보를 저장·불러오기(비밀번호 포함, 👁로 확인)
    • 
                
  • Oracle은 접속 전 서비스명/SID 칸을 먼저 채워야 하며, 옛 방식은 SID:ORCL 형식
